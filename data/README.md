# Local data policy

No raw dataset is packaged here. Official source: https://doi.org/10.5281/zenodo.19755088. Download only after M1 approval, verify official checksum and licenses, retain ZIP in gitignored `data/raw/`, and produce audit manifest in `data/interim/`. Never put original `.dat` in GitHub by default. Synthetic test fixtures may be committed under `data/fixtures/` with explicit labeling and generation code.
