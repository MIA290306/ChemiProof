# Research results policy

Runs M1-M6 and the M7 reproduction evidence live here; `experiment_registry.csv` lists every run and `docs/release/RESEARCH_REPORT.md` (Appendix A) maps run IDs to protocols. This folder is for reproducibility artifacts produced by future milestone code, not hand-written marketing metrics. Track a public subset of reviewed CSV/JSON figures only when licenses and scientific integrity are cleared. Every number must identify its source run/config/manifest and measurement unit.
